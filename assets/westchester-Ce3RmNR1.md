# White Plains hospital map extract

The extract contains the streets and building footprints around NewYork-Presbyterian Westchester Behavioral Health at 21 Bloomingdale Road. The clipped frame measures approximately 1.90 km east to west and 1.89 km north to south. It includes the state program marker, the campus core and the surrounding neighborhood. Both GeoJSON files use longitude, latitude in WGS84. The November 18, 2026 snapshot contains 1,205 building features and 514 street features. [Hospital location](https://www.nyp.org/locations/westchester-hudson-valley/westchester-behavioral-health) · [County GIS](https://gis.westchestercountyny.gov/)

## Campus identity

The operator's grounds map labels the Center Building at the middle of a distinctive connected, branching complex. Its plan, paired courtyards and neighboring detached buildings match county Buildings object **274916**. The GIS polygon groups multiple wings. Use **Main hospital complex** as its exterior label. This is a visual site-plan match. County building attributes provide geometry and measurements only. A point inside this footprint suitable for a camera target is **−73.7538926, 41.0275733**. The mathematical centroid falls in a courtyard. [Operator's grounds map](https://www.nyp.org/sites/default/files/acquiadam/2020-09/nyp_westchester_grounds_map.pdf) · [County feature](https://giswww.westchestergov.com/arcgis/rest/services/DataHub_BasemapPlanimetrics/MapServer/5/274916)

The state's OMH program marker for 9080:020 is **−73.75835, 41.02954**, roughly 435 m northwest of the interior point. Keep it as the program marker in the regional map. The county's older hospital point also uses the street address and lies approximately 0.6 km northwest of the complex. Each coordinate carries its own source and purpose. The grounds map gives no receiving location for a simulated episode. [NYS OMH programs](https://data.ny.gov/Human-Services/Local-Mental-Health-Programs/6nvr-tbv8) · [County hospital point](https://giswww.westchestergov.com/arcgis/rest/services/MappingWestchesterCounty/MapServer/13/1)

## Geometry and height

| File | Source | Retained attributes |
| --- | --- | --- |
| `buildings.geojson` | April 2023 county planimetric release. Individual photography dates vary. | County object ID, description, source photo date, source roof and base elevation, source height, derived estimated height in meters. [Buildings item](https://www.arcgis.com/home/item.html?id=bb6d28e097424a25a6ad0d33c6be3a68) |
| `streets.geojson` | County road centerlines updated in April 2024. | County object ID and street name. A null name remains null. [Streets item](https://www.arcgis.com/home/item.html?id=cea6dfb42cec44a587687d88f5d9987b) |

The county publishes `ACTUAL_HEIGHT`, `APPROX_ROOF_ELEVATION` and `BASE_ELEVATION`. All 1,205 retained heights are positive and equal the published roof-minus-base difference. We interpret those elevation numbers as feet. At the main complex the published base is 248, roof is 293 and height is 45. The USGS independent one-meter ground sample at the interior point returns 245.99 feet. The published county schema leaves the attribute units implicit. The derived `height_m` therefore supports approximate extrusion, with one scalar height per outline. The main complex gives 13.716 m by this method. Its separate clocktower and roof forms are unresolved. [County layer fields](https://giswww.westchestergov.com/arcgis/rest/services/DataHub_BasemapPlanimetrics/MapServer/5) · [USGS point query in feet](https://epqs.nationalmap.gov/v1/json?x=-73.7538926&y=41.0275733&wkid=4326&units=Feet&includeDate=True)

## Reproduction

Use Python 3 and Shapely 2.1.2. The original handoff contains `assets/campuses/ny_nyp_westchester_bh/reproduce.py`. Run that script in an environment with access to the public county service. The script queries object IDs intersecting the frame, fetches all IDs in batches and verifies every returned ID. It then intersects actual shapes with the frame, omits empty or lower-dimensional intersections, preserves holes, and rounds coordinates to seven decimal places. Output features are sorted by county object ID. All inputs are public and no key is required. The two files and `manifest.json` are regenerated together. Refreshes can change when the publisher revises the data.
